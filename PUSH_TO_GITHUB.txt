                        IMPORTANT NOTES

⚠️ SECURITY:
   - .env files NOT in repository (ignored by .gitignore)
   - node_modules NOT in repository (reinstalled via npm install)
   - JWT secrets not hardcoded
   - Passwords hashed with bcryptjs
   - Data isolated by tenantId at middleware level

⚠️ LIMITATIONS:
   - Single MongoDB instance (no distributed transactions)
   - JWT tokens valid until expiry (no immediate revocation)
   - Single server deployment (max ~1000 concurrent users)
   - No payment processing
   - No email notifications
   - Socket.io offline fallback to polling

⚠️ DEPLOYMENT:
   - Use environment variables for MongoDB URI
   - Set JWT_SECRET to strong value (min 32 chars)
   - Use HTTPS in production
   - Set NODE_ENV=production
   - Use process manager (PM2, Forever)
